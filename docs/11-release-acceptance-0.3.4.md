## 回滚与备份

- VPS 程序回滚：2026-08-18 演练成功。备份与恢复的二进制 SHA-256 一致，服务就绪检查及回滚后虚构消息投递均通过。
- SQLite 恢复：自动化测试以虚构待发消息复制数据库并重新打开验证内容可读；生产数据库默认不备份，以免延长短信正文保留时间。
- Android 签名材料：正式签名文件与密码已由用户分别备份，但外部副本的位置尚未提供给验收过程；在从该副本恢复并验证正式构建前，此项保持待完成。

当前不宣布最终生产验收完成。阻塞项为外部签名备份恢复演练，以及 T-004、T-009、正式包 T-010/T-016；SIM 1 需作为运营商环境例外取得用户接受或在恢复服务后补测。
