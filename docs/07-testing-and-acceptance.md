# 测试与验收标准

## 1. 测试层级

- 单元测试：纯业务逻辑、格式化、状态机、签名和清理条件。
- 集成测试：API、SQLite、邮件适配器和数据库迁移。
- 安卓仪器测试：权限、Room、WorkManager 和界面状态。
- 真机测试：OPPO 双卡、ColorOS 后台限制和重启恢复。
- 端到端测试：真实手机 → VPS → Gmail → iPhone 通知。

所有自动化测试使用虚构数据。

| 编号 | 场景 | 预期结果 |

| T-001 | SIM 1 收到单段短信 | Gmail 收到一封完整邮件，SIM 标识正确或明确未知 |

## 3. 安全测试

- 无 HTTPS 或证书错误时请求失败。
- 错误签名、过期时间戳和重复随机数被拒绝。
- 超长正文和畸形 JSON 被安全拒绝。
- 日志、诊断导出和错误界面不包含正文、验证码或密钥。
- APK 和仓库中不存在生产邮件凭据。
- 数据库文件权限和服务账号权限正确。
- 24小时清理覆盖失败队列、成功记录和备份策略。

## 4. 性能与可靠性

- 在目标 VPS 上持续运行不发生明显内存增长。
- 单用户正常短信量下 CPU、内存和磁盘占用稳定。
- 网络正常时，大多数邮件在短信收到后1分钟内到达 Gmail。
- 连续接收多条短信时不丢失、不串内容、不重复。
- 真机锁屏待机24小时后仍可接收并转发；期间被 ColorOS 清理的短信应在服务恢复后自动补发。

## 5. 发布门槛

发布前必须满足：

- 所有单元和集成测试通过。
- T-001 至 T-019 全部通过，或用户书面接受明确例外。
- 无已知会丢短信、泄露密钥、重复轰炸邮件或绕过认证的问题。
- 完成至少一次全新安装和一次升级安装测试。
- 完成服务端备份/恢复与回滚演练；备份不得延长短信正文保留期。
- 安装、ColorOS 设置、故障排查和卸载说明完整。

## 6. 验收记录格式

每次候选发布记录：

- App 和服务端版本。
- 测试日期及测试设备。
- VPS 环境版本。
- 各用例结果与证据。
- 已知限制。
- 是否达到发布门槛。

证据截图和日志必须遮盖短信正文、验证码、邮箱和服务器敏感信息。
