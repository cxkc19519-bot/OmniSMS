# OmniSMS 安卓短信探针

这是阶段 0 使用的本地验证 App，不是正式产品。

## 安全边界

- Manifest 不声明 `INTERNET` 权限，无法联网上传短信。
- 0.3.0 使用带持续通知的前台服务和 Direct Boot，验证 ColorOS 划掉任务及重启后的接收可靠性；通知不显示短信内容。
- 不保存完整短信正文，只保存字符数和 SHA-256 摘要前缀。
- 发送方仅保留最后4位。
- 保存系统提供的数字型 SIM/卡槽元数据，用来验证双卡兼容性。

## 验证范围

- Android 12 上的 `SMS_RECEIVED` 广播。
- 双卡短信的 SIM/卡槽标识。
- 多段短信是否被正确组合。
- ColorOS 锁屏和省电状态下能否接收。
- 手机重启后 `BOOT_COMPLETED` 是否到达。

## 安装

推荐安装包：`artifacts/OmniSMS-SmsProbe-v0.3.0-debug.apk`

1. 把 APK 传到 OPPO 手机并打开。
2. 如果系统提示禁止安装未知应用，只对当前用来打开 APK 的应用临时允许“安装未知应用”。
3. 安装后打开“OmniSMS 可行性验证”，点击“授予短信权限”并选择允许。
4. 按 App 内按钮进入系统设置，允许后台活动，并关闭该 App 的耗电异常优化。

系统可能提示此 App 是旧版或来自未知来源；这是个人侧载的调试签名测试包，不要关闭系统的全局安全保护。测试结束后可以撤销“安装未知应用”权限。

## 真机测试

测试时不要把短信正文、验证码、手机号、IMEI 或截图发到聊天中，只报告下列字段和是否成功：

1. 单卡 1：向第一张 SIM 发送普通测试短信，打开 App 点“刷新验证结果”，记录短信分段数和 SIM 元数据。
2. 单卡 2：向第二张 SIM 重复上一步。
3. 长短信：发送一条至少 160 个英文字符或 80 个汉字的虚构文本，检查“短信分段”是否大于 1。
4. 锁屏：锁屏 10 分钟后发送测试短信，再解锁刷新结果。
5. 清理后台：从最近任务划掉 App 后发送测试短信，再打开 App 查看。
6. 重启：重启手机，先不要打开 App；开机后发送测试短信，再打开 App 查看短信记录和启动记录。

每个场景只需要回复“收到/未收到”、分段数、SIM 元数据（如有）和大约延迟。摘要值无需发送。
